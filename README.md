# 🫀 Análisis Estadístico de Riesgo Cardiovascular con Python

Este proyecto corresponde al desarrollo de una prueba final en el contexto de un curso de análisis estadístico con Python. El objetivo es realizar una exploración y modelación de un dataset clínico (`cardio.csv`) proporcionado por la OMS, centrado en variables que influyen en la probabilidad de desarrollar enfermedades cardiovasculares.

## 📌 Descripción del Proyecto

La base de datos incluye variables cuantitativas y cualitativas relacionadas con la salud de pacientes, tales como presión arterial, colesterol, glucosa, tabaquismo, sexo, edad, entre otros. El propósito es aplicar técnicas estadísticas y modelos predictivos para comprender mejor los factores de riesgo.

## 🔍 Objetivos del análisis

1. **Exploración y limpieza** de datos, identificando nulos y outliers.
2. **Análisis descriptivo** de variables cuantitativas con indicadores y gráficos.
3. **Análisis probabilístico e inferencial**: cálculo de probabilidades, prueba de hipótesis.
4. **Regresión lineal**: modelo explicativo del Índice de Masa Corporal (BMI).
5. **Regresión logística**: predicción del riesgo de enfermedad coronaria a 10 años.
6. **Comparación de modelos** segmentados por variables categóricas.

## 🧪 Herramientas y librerías utilizadas

- Python 3.12+
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- SciPy
- Jupyter Notebook
